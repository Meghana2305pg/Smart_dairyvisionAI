## 6. Interpretation

### 6.1 Does adding weather features (B) improve XGBoost over bio-only (A)?

**No — it slightly worsens performance.** Adding raw `temperature`, `humidity`, and `temp_humidity` increases test MAE from 2.0877 to 2.1061 L (+0.0184 L, +0.9%) and lowers R² from 0.1430 to 0.1417. CV MAE also rises. This is counter-intuitive but explainable: the synthetically assigned weather values carry near-zero genuine predictive signal for milk yield. XGBoost, unlike Linear Regression, can learn spurious interactions between these noisy weather features and the biological inputs, which introduces overfitting to noise — manifesting as higher test-set error when irrelevant features are added.

### 6.2 Does adding THI features (C) help over bio+weather (B)?

**Marginally — test MAE recovers slightly (2.1061 → 2.0944) but remains above bio-only (A).** R² continues to decline slightly (0.1417 → 0.1408). The THI-related features (`thi_squared`, `feed_thi_interaction`) partially compensate for the noise introduced by raw weather variables, but the overall effect is neutral to slightly negative relative to bio-only.

### 6.3 Why does XGBoost underperform Linear Regression here?

This result is dataset-specific and scientifically important:

1. **Synthetically assigned weather is decorrelated from yield.** Because per-animal temperature and humidity were generated by `assign_weather()` using a seeded random process (not observed meteorological data), no genuine causal link exists between weather and milk yield in this dataset. XGBoost's tree structure allows it to fit noisy feature interactions, increasing variance on unseen data.

2. **Linear Regression is a regularising choice for uninformative features.** When weather features have zero true predictive value, the OLS estimator assigns them near-zero coefficients and the bias-variance trade-off favours simplicity. XGBoost, optimized for expressive split-based modelling, extracts more complex (but spurious) patterns.

3. **Low overall R² (~0.14–0.19).** Most yield variance is unexplained by either model; the differences between models and experiments are small in absolute terms and within each model's CV standard deviation.

4. **This does not invalidate XGBoost as the primary model.** On the full 12-feature dataset with the corrected THI formula, the five-model comparison showed XGBoost achieved the best CV MAE (1.9902 ± 0.0619) across all models. The ablation isolates the marginal contribution of feature subsets; the full 12-feature XGBoost (Experiment C baseline) performs comparably to its 6-feature ablation.

### 6.4 Key contrast with Linear Regression ablation

The LR ablation showed monotonically improving R² (0.1826 → 0.1833 → 0.1840) as features were added, while XGBoost shows the opposite (0.1430 → 0.1417 → 0.1408). This divergence reflects the different bias-variance profiles of the two model families under low-signal, noisy feature conditions.

---

## 7. Limitations

- **Statistical power is low:** Five CV folds produce MAE differences smaller than within-fold standard deviation. Differences between experiments should be treated as directional, not statistically definitive.
- **Synthetic weather:** As noted in the Linear Regression ablation, real field data with matched meteorological observations would be expected to produce clearer weather-feature benefits.
- **No hyperparameter retuning:** The XGBoost hyperparameters were fixed to the original baseline (tuned for 12 features). Performance on 6 or 9 features may improve with experiment-specific tuning, but this was explicitly excluded per task specification.
- **No SHAP analysis:** Feature importance attribution per experiment was not computed at this stage.

## 9. Conclusion

For the XGBoost model on this dataset, adding weather and THI features does **not** improve predictive performance relative to biological features alone. The bio-only experiment (A) produces the best test MAE (2.0877 L) and R² (0.1430) for XGBoost.

Across both ablation studies, **Linear Regression outperforms XGBoost** on all three feature sets and all four metrics. This outcome is consistent with the synthetic weather generation methodology: Linear Regression is more robust to uninformative features under OLS estimation, while XGBoost's expressive capacity introduces slight overfitting to noisy weather signals.

The corrected THI formula (+46.4) is confirmed as applied correctly in all experiments. The results demonstrate that the value of the THI correction lies primarily in scientific accuracy, not in a large improvement in this specific dataset's predictive metrics — a finding consistent with the Linear Regression ablation.
